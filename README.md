## Qu’est-ce que Contexte Nano Notion?

Contexte Nano Notion permet à ChatGPT d’utiliser Notion comme mémoire de travail entre plusieurs conversations.

Un **Contexte** correspond à une mission : recherche, article, projet, analyse, etc.

## Comment l’installer ?

1. Dans une conversation neuve avec Notion connecté, lancer le **Prompt d'initialisation**.
2. Indiquer où installer Contexte V2 dans Notion.
3. Créer idéalement un **projet ChatGPT vierge**.
4. Connecter Notion à ce projet.
5. Copier le contenu de la page **Directives** dans les directives du projet ChatGPT.

Les conversations utilisant Contexte V2 doivent ensuite être ouvertes dans ce projet ChatGPT.

## Comment l’utiliser ?

### Reprendre un Contexte

`Ouvre <nom du contexte>`

### Créer un Contexte

Le demander simplement en langage naturel.

### Commandes utiles

- `Persiste <contenu>` — ajoute ce contenu tel quel à la fin de la source de session du jour.
- `Source <fichier ou lien>` — ajoute une source.
- `Ingère` — traite les nouvelles sources.
- `Todo <action>` — ajoute une tâche.
- `Décision <contenu>` — enregistre une décision.
- `Decision record <contenu>` — documente un arbitrage.
- `Contradiction <contenu>` — enregistre une contradiction.
- `Directive <contenu>` — ajoute une règle au Contexte.
- `Sauvegarde` — prépare la reprise dans une prochaine conversation.
- `Vérifie` — contrôle la cohérence du Contexte.
- `Répare` — reconstruit les registres.
- `Archive` — archive le Contexte.

Pour produire un livrable, le demander simplement en langage naturel.
